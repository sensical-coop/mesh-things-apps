# Shared/common copy — Español copy

Edita el texto dentro de cada bloque de código y después entrega este archivo para que los cambios se apliquen a la aplicación. Deja los encabezados `##` (el id) y los bloques de código tal cual están — así es como un cambio se vincula al mensaje correcto. Si no quieres cambiar un bloque, déjalo igual. Consulta [`docs/copy-editing.md`](../copy-editing.md) para el proceso completo.
